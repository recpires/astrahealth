# AI assistance disclosure

Team ANGARIS used an AI coding assistant — **Claude Code (Anthropic)** — to build this NASA Space Apps Challenge 2026
prototype from the team's written brief ("Prompt Mestre — ASTRA Health").

## AI-assisted content

| Area | Files | Nature of assistance |
|------|-------|----------------------|
| Application source code | `src/**` | Generated by the assistant from the brief |
| Simulated scenario data | `scripts/generate-scenarios.mjs`, `src/data/scenarios/*.json` | Generator written by the assistant; the JSON is its seeded output |
| Demonstration procedures | `src/data/procedures.json` | Written by the assistant as illustrative, non-clinical safety steps |
| Provisional thresholds | `src/config/reference-ranges.ts` | Placeholder values chosen by the assistant for demonstration; **not** from a NASA resource |
| Interface text (English) | `src/components/**` | Written by the assistant |
| Tests | `tests/**` | Written by the assistant |
| Documentation | `README.md`, `docs/**`, this file | Written by the assistant |
| Screenshots | `docs/screenshots/*.png` | Captured automatically from the running app by `scripts/screenshots.cjs` (not AI-generated images) |

Commits created with the assistant carry a `Co-Authored-By: Claude` trailer in the git history.

## What the AI did NOT do

- It did not select, verify or integrate a NASA scientific resource. That slot is intentionally empty
  (`src/config/scientific-sources.ts`) until the team confirms it.
- It did not use real astronaut, patient or NASA data.
- No AI model runs inside the application. All analysis is deterministic and rule-based.

## Human responsibilities (Team ANGARIS)

- Review all AI-assisted code and content before submission.
- Confirm the official challenge statement and the NASA resource, then update thresholds and documentation.
- Keep the demonstration and medical disclaimers in every presentation of the project.
